For this part of the assignment I created a multiview drawing of my part in solidworks. I added tolerances and measurements needed. 


Reflections:

I used the stress equations for this model as opposed to the stiffness equations because i got bigger values for my parts using the stiffness equations. One specific value that the stress equations dictated in my model was the thickness of part B. I typed in my values into a parametric equations and used the value derived with it to use as my thickness for part be rather than typing it by hand or using the value i calculated by hand because it would be easier to work with and change if needed. That valued stayed the same throughout my whole process and did not need to be changed later on, the rest of the model responded well on its own not much manual work needed to be done to chnage things around on it.

I applied a looser tolerance at the dimension used for the height of C. That part would need to be mounted somewhere or attached to something so it would need a bigger tolerance than other parts so if i were to have given a a tighter tolerance there could be issues that arise later on in the use of the bracket.
